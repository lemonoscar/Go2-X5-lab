# User Documents

Use this directory for documents that a developer reads to install, configure, train, replay, visualize, or operate the project.

- `environment.md`: installation and environment setup.
- `network_and_framework.md`: Isaac Lab, ManagerBased env, RSL-RL, and policy contract overview.
- `go2_x5_wholebody.md`: RoboDuet `019999` WholeBody 10-D inference import, command, replay, and diagnostics.
- `training_and_replay.md`: training, resume, replay, map replay, and checkpoint migration.
- `keyboard_control.md`: keyboard control.
- `camera_visualization.md`: camera visualization and image checks.
- `vla_sft.md`: VLA-SFT overview.
- `vla_sft_layer1_usage.md`: VLA-SFT Layer 1 usage.
- `vla_sft_layer2_usage.md`: VLA-SFT Layer 2 usage.
- `vla_sft_visualization.md`: VLA-SFT scene visualization.
- `vla_sft_scene_parameters.yaml`: VLA-SFT scene parameters.
